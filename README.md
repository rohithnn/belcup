# 🏆 BEL CUP 2026 — Badminton Tournament Website

A static promotional website for the **BEL CUP 2026** badminton tournament, organized by Bharath Nagar 2nd Stage Residents Welfare Committee & Bharath Nava Yuva Association.

## 📅 Event Details

- **Date:** 14 June 2026
- **Venue:** Benaka Sports Line, Bharath Nagar 2nd Stage, Bengaluru

## 📁 Project Structure

```
ng/
├── index.html   # Main HTML page
├── style.css    # Stylesheet (dark purple + neon green theme)
└── script.js    # Navbar, countdown timer, scroll reveal, mobile menu
```

## 🚀 Getting Started

No build tools needed. Just open `index.html` in any browser:

```
Double-click index.html
```

Or serve locally with VS Code Live Server / any static server.

## ✨ Features

- Live countdown timer to the event date
- Sticky navbar with mobile hamburger menu
- Sections: About, Highlights, Prizes, Registration Fees, Rules, Contact
- WhatsApp & Call quick-action buttons for organizers
- Google Maps venue link
- Scroll-reveal animations & neon glow effects
- Fully responsive (desktop, tablet, mobile)
